## API

### タスク作成

#### エンドポイント

| リソース   | メソッド | エンドポイント | 機能概要           |
| ---------- | -------- | -------------- | ------------------ |
| タスク作成 | POST     | `/tasks`       | 新しいタスクを作成 |

#### リクエスト

```json
{
    title: string
    description: string
}
```

#### レスポンス
```json
{
    id
    title
    description
}
```

### タスク一覧
#### エンドポイント
| リソース   | メソッド | エンドポイント | 機能概要               |
| ---------- | -------- | -------------- | ---------------------- |
| タスク一覧 | GET      | `/`            | 全てのタスクを取得する |

#### リクエスト
```json
なし
```

#### レスポンス
```json
{
    title
    description
}
```

### タスク完了
#### エンドポイント
| リソース   | メソッド | エンドポイント | 機能概要               |
| ---------- | -------- | -------------- | ---------------------- |
| タスク完了 | PATCH    | `/task/:id`     | タスクを完了状態にする |

#### リクエスト
```json
{
  completed: boolean
}
```

#### レスポンス
```json
{
  {
    id
    title
    description
    completed
  },
  {task},
  {task}
}
```
