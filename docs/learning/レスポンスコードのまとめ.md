# HTTPレスポンスコード逆引き辞典 📚
学習用に、API開発でよく使うステータスコードを「見やすさ重視」でまとめました。

## 🚀 成功系（200番台）
**「リクエストは成功したよ！」** というメッセージです。

| コード | 役割 | 意味・覚え方 | 実装例（Node.js/Express） |
| :--- | :--- | :--- | :--- |
| **200** | ✅ OK | **「はい、どうぞ」**<br>データの取得(GET)や更新(PUT)が成功したとき。 | `res.json(data)` |
| **201** | ✨ Created | **「新しく作ったよ！」**<br>新規作成(POST)が成功してリソースが作られたとき。 | `res.status(201).json(data)` |
| **204** | 📭 No Content | **「完了！でも中身は空だよ」**<br>削除(DELETE)成功時など、返却するデータがないとき。 | `res.sendStatus(204)` |

---

## ⚠️ クライアントエラー系（400番台）
**「リクエストの送り方に問題があるよ！」** というメッセージです。

| コード | 役割 | 意味・覚え方 | 実装例 |
| :--- | :--- | :--- | :--- |
| **400** | ❌ Bad Request | **「書き方がおかしいよ」**<br>入力バリデーションエラーの定番。 | `res.status(400).json({ error: "必須項目が漏れています" })` |
| **401** | 🔑 Unauthorized | **「あなたは誰？」**<br>ログインしていない、または認証に失敗したとき。 | `res.status(401).json({ error: "ログインが必要です" })` |
| **403** | 🚫 Forbidden | **「だめだよ」**<br>ログインはしてるけど、他人のデータを触る権限がないとき。 | `res.status(403).json({ error: "アクセス権限がありません" })` |
| **404** | 🔍 Not Found | **「見つからないよ」**<br>URLの間違いや、存在しないデータのIDを指定したとき。 | `res.status(404).json({ error: "データが存在しません" })` |

> [!TIP]
> **401 vs 403 の違い**
> - **401 (Unauthorized):** そもそも誰か分からない（ログインして！）
> - **403 (Forbidden):** 誰かは分かっているが、その操作は許されていない（権限ないよ！）

## 🔥 サーバーエラー系（500番台）
**「サーバー側（バックエンド）で問題が起きたよ！」** というメッセージです。  
プログラムのバグや、サーバー自体の不調を指します。

| コード | 役割 | 意味・意味 | 実装例 |
| :--- | :--- | :--- | :--- |
| **500** | 💥 Internal Server Error | **「（プログラム内で）爆発した」**<br>予期せぬ例外やコードのミス。 | `res.status(500).json({ error: "システムエラー" })` |
| **502** | ☁️ Bad Gateway | **「後ろのサーバーが返事しない」**<br>中継しているサーバーがエラーを受け取った。 | (インフラ側が自動で返す) |
| **503** | 💤 Service Unavailable | **「いま休憩中（メンテ中）」**<br>アクセス過多やメンテナンス。 | (インフラ側が自動で返す) |
| **504** | ⏳ Gateway Timeout | **「時間切れだよ」**<br>処理が重すぎて制限時間内に終わらなかった。 | (インフラ側が自動で返す) |

---

## 🔃 その他（300番台）
**「あっちに行ってね」** というリダイレクトのメッセージです。

- **301 Moved Permanently**: URLが永久に引っ越したとき。
- **302 Found**: 一時的に別のURLを見てほしいとき。
