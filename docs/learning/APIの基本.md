## メソッドの使い分け一覧

| メソッド [2, 3, 4, 5, 6] | 役割（CRUD）   | 具体的なアクション                       | データの変化                 |
| ------------------------ | -------------- | ---------------------------------------- | ---------------------------- |
| GET                      | Read（取得）   | 商品一覧を見る、ユーザー情報を表示する   | 変化しない（読み取り専用）   |
| POST                     | Create（作成） | 新規会員登録をする、ブログ記事を投稿する | 新しいデータが増える         |
| PUT                      | Update（置換） | プロフィール情報を全て書き換える         | 既存データが丸ごと入れ替わる |
| PATCH                    | Update（修正） | パスワードだけを変更する                 | 既存データの一部が変わる     |
| DELETE                   | Delete（削除） | 退会する、投稿を削除する                 | データが消える               |

------------------------------
## 実践的な判断ポイント
日常的な操作に例えると、使い分けがより明確になります。

   1. 「取得」なら GET
   * 掲示板を「見る」だけならGETです。URLに検索条件（?q=keywordなど）を付けて送ることもあります。
   2. 「新しく作る」なら POST
   * 「保存」ボタンを押して、サーバー側に新しいID（データ）が発行される場合はPOSTを使います。
   3. 「上書き」か「修正」か（PUT vs PATCH）
   * PUT（置換）: フォームの全項目を送り、届いた内容でデータを「作り直す」イメージです。
      * PATCH（修正）: 特定の項目（例：ステータスを「公開」から「非公開」に変えるだけ）をピンポイントで狙い撃ちするイメージです。
   4. 「消す」なら DELETE
   * 対象のIDを指定して、そのデータを削除します。 [7, 8]
